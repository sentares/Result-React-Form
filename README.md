# React Form Project

A modern form implementation with custom components, validation, and authentication flows built with React + TypeScript + Vite.

## Features

- 🛠 Custom reusable components:
  - `Button` component with variants
  - `Input` component with validation support
- 🔐 Authentication flows:
  - Login form
  - Registration form
- ✅ Form validation
- ⚡ Fast development with Vite
- 🧩 TypeScript support
- 🎨 SCSS styling

## Technologies Used

- React 19
- TypeScript
- Vite
- Sass
- Tabler Icons
- ESLint for code quality

## Installation

```bash
git clone <repo-url>
cd react-form
npm install
```

## Available Scripts

| Command           | Description                                      |
| ----------------- | ------------------------------------------------ |
| `npm run dev`     | Runs the app in development mode with hot reload |
| `npm run build`   | Builds the app for production                    |
| `npm run lint`    | Runs ESLint for code linting                     |
| `npm run preview` | Previews the production build                    |
